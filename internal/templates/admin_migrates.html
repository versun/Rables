Import from Rables Backup

Upload a Rables export ZIP (database + media) or a bare SQLite database file. Existing rows with the same id are overwritten — including your own user account (name and password). Meant for restoring onto a fresh install or back onto the site the backup came from; importing into a site that already has its own content can fail on unique fields (slug, email, …).

A Rables export ZIP or a rables.db file

Import from Server File

Files already in the server's data/imports/ directory (copied there with scp/rsync). Use this for large backups that a reverse proxy would reject — Cloudflare caps uploads at 100 MB (413 Payload Too Large). A successful import deletes the file; a failed one leaves it in place so you can fix the problem and retry.

Import from Markdown

Import articles and pages from Markdown files with YAML front matter (a Rables Markdown export: one .md file per record with type/title/slug/status/created_at/tags fields). Upload a single ZIP of files, or pick multiple .md files at once. Documents whose slug already exists are skipped, and one bad document does not abort the batch — check the logs for the result.

A ZIP of .md files, or a selection of .md files
