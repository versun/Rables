What the regex is matched against. URL Path: the request path, e.g. /old-page. Host (subdomain): the request host without port, e.g. abc.example.com; host rules run on every path of the matched host, before any path rule. The whole host must match — ^/$ anchors are optional and unmatched host text is never carried into the target.
Regular expression to match the URL path. Examples: ^/old-page$ (exact match), ^/posts/(.+)$ (with capture groups). For host rules: ^([a-z0-9-]+)\.example\.com$ matches any single-label subdomain.
Target URL or replacement pattern. Use \1, \2 etc. to reference capture groups. Examples: /new-page, /articles/\1. For host rules the target may be an absolute URL (https://google.com) or a path (/tags/\1); a path is resolved against the site URL from settings. The request's own path and query string are never appended.
Permanent redirects (301) tell search engines to update their index. Temporary redirects (302) are used for short-term changes.
