A pattern starting with / matches the URL path on any host, e.g. ^/old-page$ (exact match) or ^/posts/(.+)$ (capture groups). Anything else matches host + path, e.g. ^blog\.example\.com/blog/(.+)$; a pattern without any / (e.g. ^blog\.example\.com$) matches the whole host, every path.
