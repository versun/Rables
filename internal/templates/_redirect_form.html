Simple matches a plain address string — no regular expression needed. Advanced (regex) matches a regular expression with capture groups.
The address to match: a path (/old-page, applies on any host) or a host with an optional path (blog.example.com or blog.example.com/blog/).
A pattern starting with / matches the URL path on any host, e.g. ^/old-page$ (exact match) or ^/posts/(.+)$ (capture groups). Anything else matches host + path, e.g. ^blog\.example\.com/blog/(.+)$; a pattern without any / (e.g. ^blog\.example\.com$) matches the whole host, every path. Host + path rules must match the whole address (^/$ anchors are optional).
Target path (/new-page) or absolute URL (https://example.com). Regex rules may reference capture groups with \1, \2 etc. For rules with a host, a path target is resolved against the site URL from settings. The request's query string is never carried over.
Permanent redirects (301) tell search engines to update their index. Temporary redirects (302) are used for short-term changes.
Only enabled redirects will be active.
